SAINTS TATTOO — TABLETTE

Version : paye basée sur les ventes + archives hebdomadaires

Règles :
- Les horaires servent uniquement au suivi de présence et de durée de service.
- La paye ne dépend pas des heures.
- Quota mensuel de ventes : 5 000 $.
- Patron : 4 800 $ si le quota mensuel est atteint.
- Manager : 3 900 $ si le quota mensuel est atteint.
- Employé : 3 000 $ si le quota mensuel est atteint.
- Chaque semaine est suivie séparément.
- Le changement de semaine se fait le dimanche à 00h05 lorsque la tablette est ouverte ; si elle était fermée, l’archive est créée au prochain démarrage.
- Les anciennes ventes, dépenses, services et heures ne sont jamais supprimés.
- Les archives hebdomadaires sont consultables dans Historique > Archives.

IMPORTANT : cette version est une maquette locale navigateur. Les données sont stockées dans localStorage. Exportez régulièrement une sauvegarde JSON.
